# Обновление Voltaris на Render до V3

В репозитории действующего сервиса kaltaris замени voltaris-auth-service.jar.
Если разворачиваешь заново, положи Dockerfile, .dockerignore, postgresql.jar
и voltaris-auth-service.jar в корень. Существующие переменные Render и адрес
игрового JAR сохраняются. База получает три дополнительные колонки автоматически.
Роль PostgreSQL должна владеть таблицей voltaris_accounts или иметь право её изменить.

После деплоя /healthz возвращает ok. GET /v3/account/challenge возвращает 405.
Старый лаунчер V2 больше не входит. Раздай клиентский ZIP V3.
При первом входе старый аккаунт должен пройти миграцию с прежнего ПК либо
после сброса устройства. Существующие подписки сохраняются.
